# Privacy Policy

Last Updated: June 17, 2026

At **redsilenceapp**, we respect and protect your privacy. This Privacy Policy describes how we handle information in our desktop application.

## 1. No Collection of Personal Information
* **redsilenceapp** does NOT collect, harvest, store, or share any personal information.
* All processing of text, voice synthesis, video editing, and rendering is performed locally on your computer.

## 2. API Credentials and Authentication
* The application requires API keys and OAuth tokens (such as Google Gemini, Groq, YouTube, and TikTok) to interact with external services.
* These credentials are saved locally in your project's configuration folder (e.g., `config/settings.json`, `config/tiktok_token.json`).
* These tokens are only used to send API requests directly to Google, Groq, YouTube, and TikTok. They are never sent to us or any third-party analytics servers.

## 3. TikTok Content Posting API
* When you choose to upload a video to TikTok, the application sends the video file directly to TikTok's secure servers using HTTPS.
* The application only uses the scopes (`video.upload`, `video.publish`, `user.info.basic`) to authorize and execute the upload process you initiate.

## 4. Updates
We may update this Privacy Policy from time to time. Any changes will be posted in this repository.
